# duplicate-image-cleaner

重复图片清理器：在浏览器中找出磁盘里内容相同或相似的图片，并在核对后清理不再需要的文件。

[在线使用](https://xcndjceoi7yz.feishuapp.com/app/app_17df5ghxcy7/)

## 功能

- 选择文件夹递归扫描、选择多张图片，或加载程序生成的演示数据。
- 区分完全一致、高度相似和疑似相似图片，支持放大对比。
- 按目录筛选、大文件优先排序，统计勾选文件及其大小。
- 完全重复默认保留一份；相似组默认不勾选，每组始终至少保留一份。
- 支持原生目录授权的浏览器可删除真实文件；演示数据仅模拟清理。
- 扫描图片在浏览器本地处理。结果仅保存在当前页面内存中，刷新或关闭后需重新扫描，不保存或恢复扫描缓存。

## 删除前必读

**真实删除不进入系统回收站，无法撤销。请先备份重要图片。**

使用支持原生目录授权的浏览器，通过“选择文件夹并扫描”进入。核对结果后点击“删除文件”，检查完整清单，在弹窗输入“删除”并点击“确认”，再允许浏览器申请的写入权限。相似图片可能包含独有内容，建议先逐张放大对比。

多选图片、降级目录选择及缺少必要浏览器能力时，只支持扫描查看。扫描本身不删除文件；文件发生变化、授权失败或保留项不满足条件时会跳过，不自动重试。

删除期间不要在其他软件中编辑、移动或替换所选目录里的文件。详细行为、限制和测试方法见 [WEB-DELETION.md](WEB-DELETION.md)。

## 开发与验证

这是当前妙搭网页版的源码快照，保留 React 19、TypeScript、Vite、Tailwind CSS 与妙搭 SDK / 构建预设。不是桌面安装包，也没有配置 GitHub Pages 自动部署。

本次验证环境：Node.js 24、npm 11。安装依赖需要访问 npm 包仓库。

```bash
npm ci
npx vite --host 127.0.0.1 --port 5173
```

打开终端显示的本地地址。上述命令直接启动 Vite；项目原有的 `npm run dev` 包装脚本会处理其占用端口，不建议在同一端口运行其他程序时使用。

```bash
npm run lint
npx vitest run
npm run build
```

构建脚本保留妙搭产物布局，输出到 `dist/output` 与 `dist/output_resource`。部署到其他平台时，需要另外适配资源路径、SPA 路由回退及平台 SDK / 构建预设，不能直接把仓库当作已部署的网站。

仓库不包含 `.env.local`、密钥、用户图片、扫描记录、依赖安装目录或原有开发 Git 历史。`.spark/meta.json` 保留原应用的公开标识与模板版本，它不是访问凭证；部署到自己的妙搭应用时应使用自己的应用配置。

## 代码位置

- `src/lib/scan-engine.ts`：目录扫描和分组。
- `src/lib/phash.ts`：相似图片特征计算。
- `src/lib/file-deletion.ts`：授权、逐文件核验与删除保护。
- `src/hooks/useScanSession.tsx`：当前扫描会话。
- `src/pages/`：首页、扫描、结果和完成页面。
- `src/**/*.test.ts`：合成数据与文件操作测试。

原模板技术规范见 [TECHNICAL.md](TECHNICAL.md)，其中模板初始状态仅供参考，当前功能以代码和本 README 为准。
